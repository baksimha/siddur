# סידור

סידור דיגיטלי בנוסח ספרד, אשכנז ועדות המזרח: תפילות עם תוספות אוטומטיות לפי התאריך, תהילים, הפטרות, משנה ברורה יומי וזמני היום. עובד בלי אינטרנט.

- `www/` – האפליקציה (נבנית מ-`src/` עם esbuild, הנתונים ב-`www/data` נוצרים ע"י `prep.py` מטקסטים של ספריא).
- `android/` – עטיפת אנדרואיד. כל דחיפה ל-main בונה APK ומפרסמת אותו ב-Releases.

טקסטים: Sefaria (ספריא). לוח עברי ולימוד יומי: Hebcal.
